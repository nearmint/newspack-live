# Changelog

## 1.2.0 – Initial public release

### Newsroom

* Live coverage on any post, with Upcoming, Live and Ended states, auto-end and "Keep live".
* "Live" menu with a Lives list and a New live shortcut.
* "Live coverage" panel in the post editor; the post content is the live's description, and a separate Context box holds a bulleted list.
* Live console: embedded block editor composer, backdating, pinning, drafts and review, edit, unpublish, trash, copy link and local autosave.
* Entry labels: Breaking, Photos, Video, Key point and custom labels per live.
* Questions inbox with moderation statuses, grouping of similar questions and Q&A answers.
* Who's online in the console, and paging of the Feed, Drafts and Questions tabs.
* Team scoping with live-level capabilities: contributors propose, editors publish.
* WP-CLI commands to create lives, add entries and questions, change states and run maintenance.

### Readers

* Live page with a state badge, "Updated" time, description, Context card and pinned entry, newest first.
* Real-time updates every 30 seconds, behind a "new updates" button, with edits, removals and pins applied in place.
* Entry permalinks, "Load older updates" paging, and share links that work without JavaScript.
* "Ask a question" form with honeypot, timing check, rate limit, reCAPTCHA and Akismet support.
* Sticky aside with related coverage (category, tag, manual selection or a Newspack Collection) and an ad placement.
* State badges on lives in Homepage Posts blocks, archives, search and Query Loop titles.

### Integrations

* Newspack Content Gate, Reader Activation, Newspack Ads, Co-Authors Plus, Newspack Collections and Primary Category.
* `LiveBlogPosting` structured data, Open Graph tags per entry and Yoast SEO filters.
* Personal data exporters and erasers, cache-friendly REST responses and WordPress VIP coding standards.
